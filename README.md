# Sigrid CI example

This is an example repository that shows how you can configure
[Sigrid CI](https://docs.sigrid-says.com/sigridci-integration/using-sigridci.html). The example integration does
the following:

- Publish your repository to Sigrid after every merge (i.e. after every commit to the main/master branch).
- Receive Sigrid feedback on pull requests.
